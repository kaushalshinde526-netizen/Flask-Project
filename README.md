To-Do List Web Application
Project Overview

This is a simple To-Do List web application developed using Python Flask and SQLite3. The application allows users to add, view, and manage daily tasks through a user-friendly web interface.

Features
Add new tasks
View all tasks
Store task data in SQLite3 database
Simple and responsive user interface
Lightweight and easy to use
Technologies Used
Python
Flask
SQLite3
HTML
CSS
Database

The project uses SQLite3 as the backend database. All tasks are stored locally in a database file and retrieved dynamically using Flask routes.

Deployment

The application has been successfully deployed on PythonAnywhere, a cloud platform for hosting Python web applications.

Deployment Steps
Create a PythonAnywhere account.
Upload project files.
Create a virtual environment.

Install required packages:

pip install flask
Configure the WSGI file.
Set the Flask application path.
Reload the web application.
